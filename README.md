# VINYL ARCHIVE

レコードのジャケット写真、作品情報、コンディション、購入価格、中古市場価格をまとめて管理する個人向けウェブアプリです。

## iPhoneでアプリを開く

### GitHubアプリから開く

1. iPhoneのGitHubアプリでこのリポジトリを開きます。
2. READMEにある **[VINYL ARCHIVEを開く](https://yuyakawamura-blip.github.io/vinyl-archive/)** をタップします。
3. GitHubアプリ内でページが開いたら、そのまま利用できます。

### Google Chromeからホーム画面にアプリとして追加する（おすすめ）

1. GitHubアプリ内でVINYL ARCHIVEを開きます。
2. 共有ボタンまたは「…」メニューから **Google Chromeで開く** を選びます。
3. Google Chromeで共有ボタン（四角から上向き矢印）をタップします。
4. **ホーム画面に追加** を選び、右上の **追加** をタップします。
5. 次回からは、iPhoneのホーム画面に追加された **VINYL ARCHIVE** アイコンをタップして起動できます。

> クラウド同期の有効化後は、同じメールアドレスでログインしたiPhoneとiMacに自動同期します。オフライン時は一度端末内に保持し、通信が戻ると自動送信します。アプリ内カメラで撮影した写真は、iPhoneの写真ライブラリには保存されません。

## 数百枚のレコードをまとめて登録する

1. 画面右上の **撮影・一括追加** をタップします。
2. **連続撮影を開始** をタップします。
3. レコードを「撮る、撮る、撮る」の要領で続けて撮影します。撮影できるたびに白いフラッシュ、シャッターボタンの反応、撮影済みサムネイル、枚数カウンターのモーションが表示されます。
4. 全部撮り終えたら **撮影完了** をタップします。
5. サムネイルをまとめて確認し、不要な写真だけ削除します。
6. **まとめてアップロード** を1回タップします。
7. 写真はクラウドへ自動同期され、Gemini 2.5 Flash-LiteによるAI解析が自動で始まります。手動の解析操作は必要ありません。

既に撮影済みの写真がある場合は、**写真をまとめて選択** から複数枚を一度に追加できます。

> AIはアーティスト名、タイトル、年代、ジャンル、カタログ番号、A面・B面の候補を入力します。写真から判断できない内容や信頼度の低い結果は「AI確認待ち」として残し、誤った断定を避けます。

### iPhoneでボタンが反応しない場合

- カメラが許可されていない場合は、iPhoneの **設定 → Chrome → カメラ** をオンにします。
- アプリ内カメラを起動できない環境では、自動的にiPhoneの標準カメラへ切り替わります。
- 写真の一括選択はiOSでも確実に開けるよう、標準の写真選択画面へ直接つながるボタンを使用しています。
- 更新前の画面が残る場合は、一度アプリを完全に閉じてから開き直してください。

## ブラウザ版のニュース欄

通常のブラウザで開いたトップページには、所蔵レコードのアーティスト・作品に関連する最新ニュースへのリンクが表示されます。iPhoneのホーム画面から起動するアプリ版ではニュース欄を表示せず、所蔵管理と連続撮影に集中できる構成です。

## 現在できること

- ジャケット写真付きでレコードを登録
- iPhoneの背面カメラをアプリ内で起動して撮影（写真ライブラリには保存しない）
- 複数のレコードを連続撮影または一括選択し、「AI解析待ち」としてまとめて保存
- AI解析待ち・解析中・確認待ち・完了のステータスを記録
- Gemini 2.5 Flash-Liteで写真を自動解析し、候補を自動保存
- iPhoneとiMacの間で起動時・保存直後・オンライン復帰時に強制自動同期
- アーティスト、タイトル、年代、ジャンル、コンディション、カタログ番号を管理
- 7インチのA面・B面曲名と音源URLを個別に記録
- 各曲からApple Music（最優先）、Spotify、YouTube、SoundCloudの検索または登録済み音源へ移動
- ブラウザ版のトップで、所蔵アーティスト・作品に関連する最新ニュースを検索（ホーム画面から起動するアプリ版では非表示）
- 検索、ジャンル絞り込み、並べ替え
- グリッド表示とリスト表示の切り替え
- 購入価格と参考相場の差額を集計
- Yahoo!オークションの過去落札相場とメルカリの現在出品相場をワンクリック検索
- JSONバックアップの書き出し
- ブラウザのアプリ用データベース（IndexedDB）に保存
- ホーム画面へ追加してPWAとして利用

## 自動同期とAI解析

- Supabase Authで同じメールアドレスにログインした端末だけが同じコレクションを共有します。
- レコード行と写真ストレージにはRow Level Securityを設定し、本人以外は読み書きできません。
- 保存直後、アプリ起動時、オンライン復帰時に自動同期します。手動同期は不要です。
- iPhoneに既にある端末内データも、最初のログイン後に自動アップロードします。
- 写真の保存後、Supabase Edge FunctionからGemini 2.5 Flash-Liteを呼び出して自動解析します。
- Gemini APIキーはGitHubやブラウザには置かず、Supabase Edge Function Secretsの `GEMINI_API_KEY` にだけ保存します。
- 無料枠には回数・速度の上限があります。上限到達時は「AI解析待ち」のまま保持し、次回同期時に再試行します。
