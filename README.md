# VINYL ARCHIVE

レコードのジャケット写真、作品情報、コンディション、購入価格、中古市場価格をまとめて管理する個人向けウェブアプリです。

## 現在できること

- ジャケット写真付きでレコードを登録
- iPhoneの背面カメラをアプリ内で起動して撮影（写真ライブラリには保存しない）
- アーティスト、タイトル、年代、ジャンル、コンディション、カタログ番号を管理
- 検索、ジャンル絞り込み、並べ替え
- グリッド表示とリスト表示の切り替え
- 購入価格と参考相場の差額を集計
- Yahoo!オークションの過去落札相場とメルカリの現在出品相場をワンクリック検索
- JSONバックアップの書き出し
- ブラウザのアプリ用データベース（IndexedDB）に保存
- ホーム画面へ追加してPWAとして利用

## GitHub Pages

リポジトリの Settings → Pages で、`main` ブランチのルートを公開元に指定してください。

## 次の実装候補

実際のDiscogs検索・相場取得には、APIトークンをブラウザへ露出させないバックエンドが必要です。Cloudflare Workersなどを介して、画像認識、Discogsリリース検索、マーケット統計取得、クラウドDB保存を追加できます。
