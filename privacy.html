PRIVACY

データの扱い

最終更新：2026年10月29日

要点

  • ログインせずに使う場合、レコードと写真はこの端末のブラウザにだけ保存され、運営者には送られません。
  • アカウントを作ると、メールアドレス、レコードの情報、ジャケット写真を、Supabase のサーバー（韓国・ソウルのデータセンター）に保存します。
  • 写真から情報を読み取るため、写真を Google の Gemini API に送ります。
  • AI の結果は候補です。同じ盤かどうか、曲目や価格が正しいかは、ご自身で確かめてください。
  • アクセス解析や広告は使っていません。
  • アカウントとデータは、アカウント画面からいつでも削除できます。

1. 運営者と問い合わせ先

VINYL ARCHIVE は個人が運営しています（表示名：VINYL ARCHIVE 運営者）。データの扱いに関する問い合わせ、開示・訂正・削除の請求、運営者の氏名・住所の確認は、次のアドレスへご連絡ください。

support@vinylarchive.app

2. 保存する情報

情報保存するとき保存場所
メールアドレス、パスワード（元に戻せない形に変換したもの）アカウントを作ったときSupabase
レコードの情報（アーティスト、タイトル、曲名、カタログ番号、価格、メモ、追加日など）レコードを追加・編集したときSupabase（ログインしていなければ端末内のみ）

表示の設定や同期の状態アプリを使ったとき端末のブラウザ内

3. 使う目的

  • コレクションを保存し、同じアカウントの端末どうしで同期するため
  • 写真からアーティスト・タイトル・曲名を読み取り、依頼に応じて曲目と市場価格を調べるため
  • 登録の確認やパスワード再設定のメールを送るため
  • AI の利用回数の上限を管理し、費用と不具合を把握するため
  • 問い合わせに対応するため

上の目的のほかには使わず、法令に基づく場合を除いて、本人の同意なく第三者に提供しません。

4. 外部のサービスに送る情報

アプリを動かすため、次の事業者のサービスを使っています。いずれも日本国外の事業者で、情報は日本国外で保存・処理されます。

サービス送る情報目的
Supabase（Supabase Inc.、米国。データは韓国・ソウルに保存）2. の情報のうち、端末内のもの以外すべてアカウント、データ、写真の保存と同期
Gemini API（Google LLC、米国）ジャケット写真、レコードの情報写真の読み取り、曲目と市場価格のウェブ調査
Resend（Resend, Inc.、米国。東京リージョンから送信）メールアドレス確認メールとパスワード再設定メールの送信
GitHub Pages（GitHub, Inc.、米国）、jsDelivr、Google Fonts（Google LLC、米国）アクセス時の IP アドレスやブラウザの種類（各サービスのサーバーが記録）アプリ本体、ライブラリ、文字の配信

Gemini API は有料の利用条件で使っています。Google の Gemini API 追加利用規約 では、有料の利用で送られた内容を Google の製品の改善に使わないと定めています。ただし、不正な利用を検出するため、一定期間保存されます。

米国と韓国の個人情報の保護に関する制度は、個人情報保護委員会が公表している 外国の制度に関する調査 で確認できます。アカウントを作るときに、外国の事業者へのこれらの提供について同意をいただきます。

5. AI の結果について

AI は写真に写っている文字やウェブ上の情報から候補を作ります。写真だけで同じ盤（プレスや版）を確定することはできず、曲目や価格が誤っている場合があります。根拠のある相場、AI の概算（「≈」付き）、手入力の価格は区別して表示します。売買などの判断は、ご自身で確かめたうえで行ってください。

6. 保存期間と削除

  • アカウントがある間は、データを保存します。
  • レコードを削除すると、その情報と写真をサーバーから削除します。
  • アカウントを削除すると、アカウント、すべてのレコード、写真、AI の利用量の記録を削除します。障害に備えたバックアップに残る場合がありますが、一定期間後に消えます。
  • 端末のブラウザ内のデータは、ブラウザのサイトデータを消すと削除されます。
